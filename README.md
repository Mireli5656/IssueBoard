## ✨ Features

- 🔎 Analyze any public GitHub repository
- 🟢 View open issues
- 🔴 View closed issues
- 📊 View total issue count
- 🏷️ Display issue labels
- 👤 Show issue author
- 💬 Show comment count
- 📅 Show issue creation date
- 🔗 Direct links to GitHub issues
- 🔄 Filter issues by Open / Closed / All
- 📄 Pagination
- 📱 Mobile-friendly design
- 🌙 Dark interface
- ⚡ Uses the GitHub REST API
- 🚫 No backend or database required

📖 How to Use
Open IssueBoard.
Enter a public GitHub repository:
owner/repository
Click Analyze.
Browse the repository's issues.
Use the filter to view Open, Closed, or All issues.
🔐 Privacy
IssueBoard does not require an account and does not use a backend or database.
Repository information is retrieved directly from the public GitHub REST API.
